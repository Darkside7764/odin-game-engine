# Contributing to Odin Game Engine

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/odin-game-engine.git`
3. Create a branch: `git checkout -b feature/my-feature`
4. Make your changes
5. Test your changes
6. Submit a Pull Request

## Code Style

- Follow Odin's official style guide
- Use `odin fmt` to format code
- Run `odin vet` and `odin check` before committing

## Commit Messages

Use conventional commits:
- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation changes
- `refactor:` Code refactoring
- `test:` Adding tests
- `chore:` Maintenance tasks

Example: `feat(renderer): add Vulkan backend support`

## Testing

- Add tests for new features
- Ensure all existing tests pass
- Test on multiple platforms when possible

## Reporting Issues

- Use the issue tracker
- Provide minimal reproduction steps
- Include Odin version, OS, and relevant logs
